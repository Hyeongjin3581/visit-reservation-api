구현할 내용: $ARGUMENTS

해당 작업 폴더(`docs/tasks/<날짜>-<기능명>/`)의 research.md가 있으면 먼저 읽어.
변경을 제안하기 전에 관련 소스 파일을 실제로 읽고, 실제 코드베이스를 기반으로 계획을 세워.

`docs/tasks/_template/plan.md` 형식으로 같은 폴더에 plan.md를 작성해. 다음을 반드시 포함해:
- 접근 방식과 이유, 버린 대안과 트레이드오프
- 수정·신규 파일 경로 목록
- 실제 변경을 보여주는 코드 스니펫
- 이번에 하지 않는 것(제외 범위)과 바꾸면 안 되는 것
- 쿼리 수·동시성·스키마 영향과 검증 방법
- 단계별 TODO 체크리스트

아직 구현하지 마.
